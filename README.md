## 🌟 About the Project

**Clockivo** is an open-source, beautifully designed suite of time-management tools built to help you stay focused and maximize your productivity. Whether you are using the Pomodoro technique to study, tracking your work hours with a stopwatch, or setting a reliable alarm for a meeting, Clockivo provides a clean, distraction-free environment.

No paywalls, no annoying ads, and no forced sign-ups. Just pure productivity wrapped in a stunning modern UI (Glassmorphism design).

## ✨ Features

- **🍅 Custom Focus Timer (Pomodoro):** Set your work intervals, track your flow state, and take perfectly timed breaks.
- **⏱️ Precision Stopwatch:** Track elapsed time with millisecond precision for any task or project.
- **🔔 Reliable Alarm Clock:** Set multiple alarms with customizable snooze and quick-presets.
- **🌙 Beautiful Dark/Light Mode:** A gorgeous UI that adapts to your preferences and reduces eye strain.
- **🧩 Companion Chrome Extension:** Manage your timers and alarms without ever leaving your current tab. The extension syncs perfectly in the background and notifies you exactly when time is up!
- **🌐 Multilingual Support & Blog:** SEO-optimized blogs built-in to learn more about time management.

## 💻 Tech Stack

Clockivo is built using modern, fast, and scalable technologies:

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & Vanilla CSS variables
- **Icons:** [Lucide React](https://lucide.dev/)
- **Chrome Extension:** Manifest V3, Web Audio API (Offscreen documents)

## 🚀 Getting Started

Follow these steps to run the Clockivo web app locally on your machine.

### Prerequisites
Make sure you have **Node.js** (v18 or higher) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/abhi478jeetur-rgb/clockivo.com-tool-website.git
   cd clockivo.com-tool-website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in Browser:**
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the app.

## 🧩 Chrome Extension Setup

Want to run the Clockivo Chrome Extension locally? Here is how:

1. Open Google Chrome and navigate to `chrome://extensions/`.
2. Toggle **"Developer mode"** ON (in the top right corner).
3. Click on **"Load unpacked"**.
4. Select the `chrome-extension` folder located inside this repository.
5. Pin the extension to your toolbar and start focusing!
